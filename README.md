# xiaoyan-junior-english

初中英语语法备课助手:用「刘晓燕老师」语法课的讲法讲清楚每个知识点,并标出课上的出处,可以点开核对;一篇语法填空逐空解析后,还能进一步做成讲评课件。

> 非官方整理,与讲师本人及视频上传者均无关联。请以老师的原视频和你所用的教材为准。

![演示:提问 must 的否定,回答带出处与跳转链接](assets/demo.gif)

## 为什么做这个

辅导孩子英语时我发现,语法对很多家长来说也讲不清;老师备课同样耗时:要找准知识点、配例句、预判学生的易错处。这个 skill 把一整套初中语法课整理成可检索的知识点索引,让 AI 按老师的讲法讲清楚,并且每个结论都标出课上的出处,可以点开核对。

## 怎么用

| 场景 | 你可以这样说 |
|---|---|
| 家长:先弄懂,再讲给孩子 | 「must 的否定为什么是 needn't?给我一个能讲给初一孩子的版本。」 |
| 老师:备课 | 「明天讲宾语从句的时态,按这个课程列出要点、例句和易错点。」 |
| 老师:讲评语法填空 | 「这是一篇语法填空,逐空解析,标出考点和课上对应的知识点。」 |
| 做课件 | 解析完成后,交给 PPT 类 skill 做成讲评课件(需另装对应 skill)。 |

![示例:一道语法填空的解析页,包含位置、依据、结论](assets/ppt-slide.png)

## 效果

> **问**:must 的否定到底是 mustn't 还是 needn't?
>
> **答**:看 must 是哪个意思。must 表"必须"时,否定是 needn't(不必);mustn't 是"禁止"。must 表"一定"(推测)时,否定是 can't。
> 老师的口诀:must 当"必须"讲,否定是 needn't;must 当"一定"讲,否定是 can't。
>
> 📌 出处:P09-10 must 的否定(约 14:35),附 B 站跳转链接。

更多示例见 [`examples/`](examples/)。

## 特点

- **有出处**:回答标注集号、知识点编号和大约时间,可直接跳转到视频。
- **标注简化说法**:老师为了好记做的简化(标 ⚠),会补充适用范围。
- **没讲到会明说**:课程没覆盖的内容不编造出处,通用解答会标明"不是老师的讲法"。
- **中英双语**:中文讲解,英文例句配中文意思,面向初中生。

## 工作原理

回答时先查 `references/course-index.md` 定位知识点编号,再只打开对应的分集文件,最后按编号给出出处。

```
SKILL.md                 触发描述、检索流程、引用格式、讲课口吻
references/
  course-index.md        总览:核心结论、按主题查找、使用注意
  ep-p01-p06.md …        逐集知识点条目(按需加载)
glossary.txt             转写纠错词表

```

## 常见问题

**准确吗?** 索引由本地语音转写整理,转写含识别错误,各分集文件末尾的"转写存疑"列出了不确定处。时间戳取转写行的起点,可能差几十秒。P21 之后的条目未逐条人工核对。

**为什么有些问题说"这门课没讲到"?** 比如虚拟语气,课上只在例句里点到一次。这时会给一个简短的通用解答,并明确标注不是老师的讲法。

**发现出处对不上怎么办?** 欢迎提 issue,附上集号和时间点。
